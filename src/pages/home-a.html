Open tide data you can check.

OpenTideConstants (OTC) is one open dataset of tidal harmonic constants. Every constant set states its licence, where it came from and which conventions it uses. Every set fitted from a gauge record also states how its clock was checked. The format is versioned, its JSON Schema is public, and every file has a SHA-256 checksum.

Helgoland. The German WSV gauge records in GESLA are in German civil time but are labelled UTC. OTC checks the clock of every gauge record before it uses it, and records what it found.

What the data tells you

A set of constants is only as useful as what you know about it. In OTC, that knowledge is part of the data, in fields that a program can read, not in a note on a web page.

  • A licence for each set, not one for the whole file

    Every set names its licence_id. The release lists each licence with its SPDX id, provider, the attribution text to show and commercial_use. Where commercial use is not allowed, the licence also says why and links the upstream terms. You can tell which stations you may ship in a paid product before you ship it.

  • Provenance

    Each set records its source, the source record and version, and the build commit that made it. A set fitted from a gauge record also records the span of data used.

  • A clock check

    Every gauge set, and every third-party analysis of a gauge record, carries a time-base code: verified, corrected, unverified or disputed, with the reason and the evidence. A clock is corrected only on positive evidence.

  • Declared conventions

    Every set states its phase reference, time zone, astronomical-argument model, nodal corrections and constituent definitions. A converter never guesses.

  • QC with reasons

    A set is ok, flagged or no_constants. Every flag has a reason, such as a short record, a broken record or an unverified clock, and the numbers behind it where they apply.

  • Attribution text

    Every licence carries the exact credit text to show where you show the data, so attribution is copied, not written by hand.

  • A time zone for every station

    Every station gives its IANA time-zone name, so local times are computed, not guessed.

The licence is in the data

This is one entry from the licence list of an OTC release build. Some gauge records come from agencies whose terms do not clearly cover derived constants. OTC keeps those sets, marks them for non-commercial use only, and links the upstream terms.

A format you can depend on

Format 1.0

OTC_{YYYYMMDD}

  • A published JSON Schema for the format, on Data format.
  • A reader gate. Each release states format_version and min_reader_version, so an old reader stops instead of misreading a newer release.
  • Dated files. Every file is named by the date of its release.
  • SHA-256 checksums for every file.
  • Stable station ids in the OTC namespace, never changed and never reused.
  • JSON, JSON Lines and CSV. JSON for programs, JSON Lines for streaming and per-station diffs, CSV for spreadsheets.

Open in the ways that matter

  • Open data, open process

    The site source and the issue tracker are public on GitHub. Anyone can report a problem with a station there. Each constant set carries its own licence, with per-provider attribution; the code is MIT.

  • Accuracy, with its label

    The Validation page sets out how accuracy is measured against official predictions: time and height errors, missed and extra events, and the predictor's own floor as a control. Each result states when it was measured and which constants were compared.

  • Citable

    The repository has a CITATION.cff, and How to cite gives the text. Each release records its datestamp, its build commit and the version of every source it used.

  • A documented method

    The Method covers fitting, the clock checks, broken and short records, set selection and the release gate. Conventions defines every convention a set can declare.
