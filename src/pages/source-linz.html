LINZ tide constituents (New Zealand)

What it is
Harmonic constants (tide constituents) for New Zealand ports and coastal sites, published by LINZ as one zip file of text files.
Publisher
Toitū Te Whenua Land Information New Zealand (LINZ).
What OTC takes
Official constants: 28 to 35 constituents per site, each with its frequency, amplitude (in centimetres) and phase. The file headers give TIME ZONE = 180, so the phases appear to be referenced to New Zealand time; OTC checks this against LINZ's own predictions, converts the phases to Greenwich and records the conversion. Some header details are wrong (Nelson's header latitude, for example), so OTC does not trust the header metadata and takes positions from the LINZ station list.
Licence
CC BY 4.0, the default licence for LINZ content, as stated on the LINZ copyright page. Attribution must be in text, not a logo.
Attribution line OTC uses
“Contains data from Toitū Te Whenua Land Information New Zealand, CC BY 4.0.”
Access and watching
Keyless download of the zip file linked from the LINZ tide constituents page. The file's address contains its date, so the watcher finds the link on that page and records the file's SHA-256 hash. It also hashes the LINZ copyright page. LINZ updates major ports every year and other sites about every 3 years.
Coverage
56 New Zealand sites. About 39 of them are not in GESLA.
Rank
Official constants.
Provenance keys
Each LINZ set adds to its provenance: member (the *_Harm_* file in the zip), header_dropped (which header fields are not used, and why), and position: the header position (header_lat, header_lon; null when the header position cannot be read; the station list then gives the position), the station-list position when the port is listed (list_port, list_lat, list_lon, list_distance_km), where the published position comes from (from: header or station_list), checked (false when the check was not run), and replaced_because when the station list replaced the header.
