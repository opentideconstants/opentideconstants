FES2022 global ocean tide model

Access confirmed. Public release pending. OTC acquired the FES2022b ocean elevation grids and implemented station-point processing. Release validation is in progress. The data release is not public yet.

What it is
A global ocean tide model with 34 constituents at 1/30° resolution.
Publisher
CNES, LEGOS, Noveltis and CLS, distributed through AVISO+.
What OTC takes
Model constants: elevation amplitude and phase interpolated from the ocean grids to station points. Every such set is labelled as model constants. OTC never re-hosts the grids and does not use the FES2022 currents.
Prediction limitations
Predictions use 32 supported ocean constituents. The original MSQM and MTM coefficients are retained with their provenance but are unsupported for predictions. Masked points remain explicitly unavailable. These constants establish neither an absolute mean sea level nor a chart-datum tie.
Quality
Model sets carry the reliability_withheld fallback label. The gauge comparison found a median absolute phase difference of 3.624°. This exceeds the unchanged 2° limit. OTC retains the coefficients and records this failed check. This comparison does not establish calibrated station accuracy.
Licence
The AVISO License Agreement (Issue 20), based on CC BY 4.0. It allows derived products, such as constants at station points, but not the onward distribution of the original grids without written authorization from CNES. The FES currents are for non-commercial use only.
Attribution line OTC uses
“Contains model constants derived from FES2022 (Cnes/Legos/Noveltis/CLS), doi:10.24400/527896/a01-2024.004.”
Access and watching
AVISO+ access is confirmed. OTC acquired the ocean elevation grids. Additional loading-grid acquisition is in progress. The raw grids stay private. The model release is static.
Coverage
The global ocean.
Rank
Model constants rank below official constants, gauge fits and third-party analyses. Existing preferred sets remain preferred.
