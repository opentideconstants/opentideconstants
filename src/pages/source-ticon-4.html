TICON-4

What it is
Harmonic constants fitted from the GESLA-4 sea-level records, one set per record: “TICON-4: TIdal CONstants based on GESLA-4 sea-level records” (2025), by Michael Hart-Davis, Denise Dettmering and Florian Seitz.
Publisher
DGFI-TUM, published on SEANOE (doi:10.17882/109129).
What OTC takes
Third-party analyses (source type analysis): the constants of a gauge whose own OTC fit cannot be published, for example because the record's licence does not allow it. OTC runs its time-base checks on those records too, and every TICON-4 set carries OTC's time-base annotation of the same record. When OTC confirms the time base, or no comparator gives a verdict, the constants are carried as published. When OTC corrects it, OTC applies the same correction to the phases and says so in provenance.modified. When the evidence disputes it, the set is not carried. Constituents whose TICON-4 definition differs from OTC's, such as M1, are left out (see Conventions). Where OTC can publish its own fit of a gauge, TICON-4 is used only as a cross-check.
Licence
CC BY 4.0.
Attribution line OTC uses
“Contains constants from TICON-4 (DGFI-TUM), CC BY 4.0. Hart-Davis, M., Dettmering, D., Seitz, F. (2025). TICON-4: TIdal CONstants based on GESLA-4 sea-level records. SEANOE. doi:10.17882/109129.” A set with provenance.modified adds what OTC changed.
Access and watching
One download from SEANOE. A release is static, so a new TICON release is a new source version.
Coverage
The GESLA-4 gauges: 4,838 in the file (the landing page gives 4,383). OTC carries only the gauges whose own fit cannot be published.
Rank
Third-party analysis: below official constants and any OTC gauge fit at the station, above model constants.
