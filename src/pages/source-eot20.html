EOT20 global ocean tide model

What it is
An empirical global ocean tide model derived from satellite altimetry, with ocean-tide and load-tide grids for 17 constituents at 1/8° resolution.
Publisher
DGFI-TUM, published on SEANOE.
What OTC takes
Model constants: amplitude and phase interpolated from the grids to station points. Every such set is labelled as model constants and scored like every other set. OTC does not re-host the grids.
Licence
CC BY 4.0, as stated on the SEANOE dataset page.
Attribution line OTC uses
“Contains model constants from EOT20 (DGFI-TUM), CC BY 4.0. Hart-Davis et al. (2021), doi:10.17882/79489.”
Access and watching
One keyless download (about 2 GB of NetCDF). The release is static, so a watcher checks the file checksum.
Coverage
The global ocean.
Rank
Model constants: used only where no official constants or gauge fit exist for the location.
