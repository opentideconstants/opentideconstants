One format. Four SDKs.

OpenTideConstants (OTC) is an open dataset of tidal harmonic constants in one versioned format. The SDKs for Python, Ruby, TypeScript and C share one interface and one conformance suite. Each one downloads a release, checks its SHA-256, caches it, and then works with no network.

Read the format → Files and downloads

Shipping a paid product? Open the SDK with commercial_only, and it keeps only the constant sets whose licence allows commercial use.

What you get

Tide constants from many publishers, in one shape, through one interface in the language you already use.

  • One format for every kind of source

    Official agency constants, OTC's fits of gauge records, third-party analyses and model constants all use the same JSON format, checked by one published JSON Schema. Every set says which kind it is, and a station's recommended set is chosen by a published rule. Your code reads one shape, whatever the source.

  • Four SDKs, one interface

    Python, Ruby, TypeScript and C have the same queries and the same error codes. All four pass one language-neutral conformance suite. The Python and Ruby SDKs use only the standard library, and the TypeScript SDK has no runtime dependencies.

  • Offline

    With offline set, an SDK never opens a socket and loads the newest release in its cache. Or bundle a release with your app and open it from a file, checked against its .sha256.

  • A commercial-use option

    Every set names its licence, and the release says whether that licence allows commercial use. commercial_only (commercialOnly in TypeScript) keeps only the sets that do, and each station's recommendation then comes from those sets.

  • Pin a release

    Open a release by its date for reproducible builds. A release that needs a newer reader fails with reader_too_old instead of being misread.

  • Find stations

    Look a station up by its OTC id or by an id in another system, search by name, or find the stations near a point or the nearest one.

  • Credit, done for you

    attribution gives the exact credit text for the stations you use, from each set's licence.

A few lines to a station's constants

The same steps work in Ruby, TypeScript and C. The SDK downloads the latest release once, checks it and caches it; after that it answers from the cache.

Or just the files

One OTC release

OTC_{YYYYMMDD}

  • JSON, also gzip-compressed, with every station and set.
  • JSON Lines, one station per line, for streaming and per-station diffs.
  • CSV, one long table for spreadsheets.
  • A metadata file with the release, conventions, licences and constituents.
  • SHA-256 checksums for every file.
  • A reader gate. format_version and min_reader_version in every release.
