Sources

This page lists every dataset OTC incorporates, what OTC takes from each, and how each one is credited.

How sources rank at one location

When more than one source covers the same location, the station's recommended set is chosen in this order:

  1. Official constants: harmonic constants published by the agency responsible for the gauge (for example NOAA, Kartverket).
  2. Gauge fit: constants OTC fits from a gauge record (GESLA).
  3. Model constants: constants from a global or regional tide model, labelled as model constants. EOT20 and FES2022 are the model sources.

Every set stays in the release files, not only the recommended one, so you can choose another. A source must also pass the per-source convention check; a source that fails is not used in that release. The validation table shows how each set scores against official predictions.

The sources

OTC combines fifteen open sources. For each one, the licence was read and the access path was checked on 2026-10-07 (LINZ and SHOM REFMAR on 2026-10-08). The coverage figures on each source's page are from those checks.

Most give gauge records, from which OTC fits its own constants. NOAA CO-OPS, Kartverket and LINZ publish official constants. EOT20 and FES2022 are global tide models: their constants are model constants, interpolated to station points, labelled as model constants in every file, and ranked below official constants and gauge fits.

  • GESLA (Global Extreme Sea Level Analysis): gauge fit.
  • NOAA CO-OPS: official constants.
  • Kartverket (Norway): official constants.
  • LINZ tide constituents (New Zealand): official constants.
  • NOAA CO-OPS tidal-current constants: official constants (currents).
  • PEGELONLINE (Germany): gauge fit.
  • Rijkswaterstaat WaterWebservices (Netherlands): gauge fit.
  • Marine Institute (Ireland): gauge fit.
  • DMI ocean observations (Denmark): gauge fit.
  • SMHI oceanographic observations (Sweden): gauge fit.
  • FMI mareographs (Finland): gauge fit.
  • UHSLC Fast Delivery: gauge fit.
  • SHOM REFMAR (France): gauge fit, from observations only.
  • EOT20 global ocean tide model: model constants.
  • FES2022 global ocean tide model: model constants.

Used only as cross-checks

These are compared with OTC on every build but are not published as OTC sources: TICON-4 (constants fitted from GESLA-4.0), the XTide harmonics files, and the Slackwater database.

Considered, not added

These sources were checked and are not added. Some of their gauges reach OTC through other sources, such as GESLA or UHSLC.

  • Canadian Hydrographic Service (CHS): no harmonic-constant endpoint; licence does not allow derivative products for commercial purposes.
  • IOC Sea Level Station Monitoring Facility (VLIZ): terms do not allow commercial use; each data provider sets its own terms.
  • TPXO10 (Oregon State University): non-commercial licence; access by registration only.
  • FEMAR catalogue (Brazil): no open licence found; no automated access.
  • SHOA (Chile): no licence statement found; the website does not allow automated access.
  • SHN (Argentina): all rights reserved; tide tables only, with no API.
  • SANHO (South Africa): copyright requires written permission to reproduce; no API.
  • Puertos del Estado, REDMAR (Spain): terms require contact before commercial use.
  • Instituto Hidrográfico (Portugal): no open licence found; data are released by request form.
  • SHOM harmonic constants and tide predictions (France): paid licence; no open SHOM constants dataset. SHOM's open REFMAR observations are used instead.
  • Bureau of Meteorology (Australia): default terms allow personal or internal use only; no published constants dataset.
