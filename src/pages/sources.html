Sources

This page lists every dataset OTC incorporates, what OTC takes from each, and how each one is credited.

How sources rank at one location

When more than one source covers the same location, the station's recommended set is chosen in this order:

  1. Official constants: harmonic constants published by the agency responsible for the gauge (for example NOAA, Kartverket).
  2. Gauge fit: constants OTC fits from a gauge record (GESLA).
  3. Model constants: constants from a global or regional tide model. None is in the launch set.

Every set stays in the release files, not only the recommended one, so you can choose another. A source must also pass the per-source convention check; a source that fails is not used in that release. The validation table shows how each set scores against official predictions.

GESLA (Global Extreme Sea Level Analysis)

What it is
A collection of high-frequency sea-level records from tide gauges worldwide, assembled from many national and regional agencies by the GESLA project. OTC uses the latest release (GESLA-4.1, July 2026, today).
What OTC takes
Gauge records that OTC fits. OTC fits its own constants from the records, after the time-base and broken-record checks in Method. OTC publishes the derived constants only, never the raw series.
Licence
The records are covered by several licences set by their originators; the GESLA licence page lists them. OTC follows TICON-4's practice: derived constants under CC BY 4.0, with per-record provider attribution and the GESLA citations. Every fitted set records its provider and licence class.
Attribution
The GESLA downloads page asks: “Any papers or reports that make use of GESLA data should include an acknowledgement to this website and cite the papers by Haigh et al. (2023) and Woodworth et al. (2017)”, and Caldwell et al. (2015) for UHSLC records. Each set also names the agency that provided the record.
Update cadence and watching
GESLA-4.0 was released in July 2025 and GESLA-4.1 in July 2026. A weekly watcher checks the version on the downloads page, the SHA-256 of the metadata file, and a hash of the licence page. A new release triggers a full rebuild and a new time-base audit of every provider.
Coverage
GESLA-4.1 has 6,682 records worldwide. How many become published stations depends on the checks, and is known only after the first full build.
Rank
Gauge fit: used where no official constants exist for the location, or where official constants fail the convention check.

NOAA CO-OPS

What it is
The Center for Operational Oceanographic Products and Services of the US National Oceanic and Atmospheric Administration, which publishes tide predictions and harmonic constants for US stations through a public API.
What OTC takes
Official constants for reference stations (Greenwich phases), and subordinate-station offsets (time and height corrections to a reference station). OTC publishes them unmodified and marks them as NOAA data.
Licence
US Government work in the public domain (LicenseRef-PublicDomain-USGov). NOAA's disclaimer says the data “may be used freely by the public” and “shall not be modified in content and then presented as official government material”. OTC never presents its files as an official NOAA product.
Attribution line OTC uses
“Contains NOAA CO-OPS data (public domain). Not an official NOAA product.”
Update cadence and watching
The API sends no ETag or Last-Modified headers, so a weekly watcher hashes the normalised response for every station and rebuilds only the stations that changed.
Coverage
NOAA's tide-prediction station list had 3,502 stations when checked on 2026-10-07: 1,260 reference stations and 2,242 subordinate stations. Mostly the United States and its territories.
Rank
Official constants.

Kartverket (Norway)

What it is
The Norwegian Mapping Authority, which operates Norway's permanent tide gauges and publishes their harmonic constants through its tide API.
What OTC takes
Official constants: amplitude, phase, speed, Doodson code and observation span per station. The API gives phases relative to UTC+1 (utcoffset="+01:00"); OTC converts them to Greenwich and records the conversion.
Licence
CC BY 4.0, as stated on Kartverket's API page.
Attribution line OTC uses
“Contains data from Kartverket (Norwegian Mapping Authority), CC BY 4.0.”
Update cadence and watching
A weekly watcher hashes the response for every station and rebuilds only the stations that changed.
Coverage
Norway's permanent tide gauges. The station count will be published with the first release.
Rank
Official constants.

Under evaluation

Not yet incorporated. These sources are being checked. A source is added only when it publishes constants or records under a licence compatible with CC BY 4.0, and passes the per-source convention check. Nothing is claimed here about their licence, coverage or quality until that check is done.

  • FEMAR (Brazil)
  • IOC sea-level station monitoring facility (VLIZ)
  • National open-data APIs of other hydrographic and sea-level agencies
  • EOT20 global tide model (would be model constants)
  • NOAA CO-OPS tidal current predictions (would be currents)

Used only as cross-checks

These are compared with OTC on every build but are not published as OTC sources: TICON-4 (constants fitted from GESLA-4.0), the XTide harmonics files, and the Slackwater database.

Checked and not used

  • Canadian Hydrographic Service (CHS): its water-level API has no harmonic-constant endpoint, and its licence does not allow derivative products for commercial purposes. Canadian stations come from GESLA records instead.
