Citation

Citing OpenTideConstants

  • Each release will have its own DOI, through Zenodo, under one concept DOI that always resolves to the latest release. DOIs are coming with the first release.
  • Cite the release you used, by its release date (YYYYMMDD) and its DOI, so others can get the same data.
  • The repository has a CITATION.cff file, which GitHub and reference managers can read.

Until the first release, cite the project as:

OpenTideConstants contributors. OpenTideConstants: open tidal harmonic constants.
{{site.url}}/ (release DOI coming with the first release).

Also cite the upstream data

OTC is derived from other people's data. When you cite OTC, also cite the sources of the stations you used; see Licence and attribution:

  • GESLA: Haigh et al. (2023) and Woodworth et al. (2017); Caldwell et al. (2015) for UHSLC records. The full references are on the GESLA downloads page.
  • NOAA CO-OPS, for NOAA constants and offsets.
  • Kartverket, for Kartverket constants.
  • Where you compare with TICON, cite the TICON release you used, for example TICON-4, doi:10.17882/109129.
